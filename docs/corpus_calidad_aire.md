# Corpus documental de AIRE IA

## PM2.5 y calidad del aire
PM2.5 corresponde al material particulado con diámetro aerodinámico inferior o igual a 2.5 micrómetros. La red de monitoreo de calidad del aire del Valle de Aburrá mide contaminantes atmosféricos y variables meteorológicas. SIATA procesa y revisa la coherencia y consistencia de los datos antes de su comunicación.

Fuente: SIATA, Calidad del aire. https://siata.gov.co/sitio_web/index.php/calidad_aire

## Categorías de referencia para PM2.5
La información institucional de Medellín presenta las siguientes categorías para PM2.5 (µg/m³): Buena, 0–12; Aceptable, 13–37; Dañina para grupos sensibles, 38–55; Dañina, 56–150; Muy dañina, 151–250; Peligrosa, 251–500. La aplicación usa límites continuos equivalentes para clasificar valores decimales. Verifica siempre la versión vigente de la norma y la metodología antes de uso público.

Fuente: Alcaldía de Medellín, Aire en el Valle de Aburrá. https://www.medellin.gov.co/es/secretaria-medio-ambiente/calidad-del-aire/aire-en-el-valle-de-aburra/

## Datos abiertos
El portal de datos abiertos del Área Metropolitana publica el conjunto “Mediciones estaciones calidad del aire”, cuyo publicador es SIATA e incluye distribuciones JSON por contaminante, entre ellas PM2.5. Para este proyecto, registra la fecha de descarga, el nombre del archivo y cualquier transformación aplicada.

Fuente: Portal de Datos Abiertos AMVA, Mediciones estaciones calidad del aire. https://datosabiertos.metropol.gov.co/node/99

## Limitaciones
Los datos de estaciones son mediciones localizadas y pueden tener faltantes, rezagos o controles de calidad. Una categoría calculada sobre una medición no equivale necesariamente al ICA oficial comunicado por las autoridades. El modelo de este MVP es experimental, no pronostica episodios críticos y no constituye consejo médico.
